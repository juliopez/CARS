Construye prompts con CARS

Contexto · Acción · Rol · Salida. Describe un problema, genera una instrucción reutilizable y evalúa la respuesta de la IA. No requiere registro ni envía tus datos a un servidor.

1. Elige un caso de trabajo

Puedes comenzar con un ejemplo o completar los campos desde cero. Todos los ejemplos usan datos ficticios.

Importante: CARS es una ayuda para organizar instrucciones, no una fórmula obligatoria. El rol es opcional y un prompt estructurado no garantiza datos correctos.

2. Completa CARS

Situación, destinatarios, información disponible y límites.
Tarea concreta, objetivo y criterios de éxito.
Perspectiva o especialidad útil, sin atribuir autoridad profesional real.
Formato, estructura, extensión y evidencia exigida.

3. Copia y prueba tu prompt

Pruébalo en el modelo de tu preferencia. Este laboratorio no ejecuta modelos de IA ni accede a documentos, servicios o datos reales.

4. Evalúa la respuesta

Tras probar el prompt, califica la respuesta con esta rúbrica didáctica. Marca 0 (insuficiente), 1 (parcial) o 2 (adecuado). No es una escala psicométrica validada.

Puntaje: 0 / 12

Si aparecen datos falsos, se divulga información confidencial o se proponen acciones no autorizadas, revisa el resultado aunque el puntaje sea alto.
