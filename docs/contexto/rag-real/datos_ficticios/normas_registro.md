# Normas de registro — escenario ficticio

[N1] Cada asesoría debe registrarse dentro de **dos días hábiles** después de realizarse.

[N2] Si faltan antecedentes del cliente, el registro permanece **pendiente de completar**. El asesor no debe inventar nombres, fechas, montos ni hechos ausentes.

[N3] El registro debe indicar fecha, tema tratado y compromisos acordados, cuando estos datos estén disponibles.

> Documento inventado exclusivamente para formación. No corresponde a normas oficiales de Sercotec.
