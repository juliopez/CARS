1. ¿La versión gratuita permite configurar un asistente?

Sí, en parte. En ChatGPT Free se pueden utilizar instrucciones personalizadas y proyectos, sujetos a límites y controles del producto. Esto permite especializar el comportamiento y proporcionar documentos de referencia sin instalar un LLM local. Sin embargo, no es equivalente a gestionar un System Prompt de API, ejecutar Skills con código o disponer de permisos para todas las integraciones.

Situación verificada al 30 de octubre de 2026: ChatGPT ya no permite crear nuevos GPT personalizados en cuentas personales Free, Go, Plus o Pro. Los GPT existentes pueden seguir disponibles y editables bajo condiciones. El producto está evolucionando hacia complementos con instrucciones, habilidades y apps. Verifica las opciones efectivamente mostradas en tu cuenta antes de una capacitación.

La forma más accesible de implementar un asistente para un participante sin programación es un proyecto con instrucciones propias, archivos de referencia y pruebas. No confundirlo con un nuevo modelo entrenado.

4. Ruta práctica sin programación

  1. Definir propósito: por ejemplo, asistente para sistematizar asesorías empresariales con datos ficticios.
  2. Crear proyecto: asignar nombre y delimitar el trabajo.
  3. Escribir instrucciones: propósito, usuarios, acciones permitidas, criterios de respuesta, fuentes y restricciones.
  4. Agregar conocimiento: adjuntar documentos autorizados, cortos y versionados; no introducir información sensible sin permiso.
  5. Probar: utilizar casos correctos, ambiguos, contradictorios y sin información.
  6. Evaluar: revisar si respeta las fuentes, reconoce límites y evita acciones no autorizadas.
  7. Mejorar: actualizar instrucciones y documentos; volver a ejecutar las pruebas.

En un chat común también puedes comenzar con un prompt de CARS, pero la especialización no necesariamente persistirá entre chats. Un proyecto facilita mantener instrucciones y materiales relacionados.

5. Generador de instrucciones para un proyecto en la nube

Este generador no crea ni configura automáticamente un proyecto en ChatGPT. Solo prepara instrucciones que puedes revisar y pegar en la configuración correspondiente.

6. De un proyecto sencillo a una Skill con herramientas

Nivel 1 · Instrucción reutilizable

Una plantilla que se pega en un chat. No tiene ejecución automática ni memoria documental propia.

Nivel 2 · Proyecto con conocimiento

Instrucciones persistentes de proyecto y documentos. Adecuado para una capacitación introductoria con Free y planes de pago elegibles.

Nivel 3 · Skill / complemento

Flujo reutilizable con pasos, referencias y, cuando está permitido, scripts o apps. Disponibilidad según producto y permisos.

Nivel 4 · Automatización o agente

Acciones en aplicaciones externas, ejecución y seguimiento; requiere autorizaciones, controles, registro de operaciones y supervisión.

Una Skill no es simplemente un prompt extenso. Una Skill puede contener un procedimiento, archivos y código; solo podrá ejecutar aquello que el entorno y sus permisos permitan.

7. Diferencias con otros servicios

Claude: dispone de proyectos con historial y base de conocimiento, incluso para usuarios gratuitos bajo límites de producto. Su implementación de proyectos y Skills es distinta a ChatGPT. Consulta documentación oficial de Claude Projects.

Gemini: distingue el uso en la aplicación de consumo, las herramientas personalizables y la API; no asumir que una suscripción Google AI habilita controles equivalentes a un System Prompt de desarrollador o una Skill ejecutable. Verificar las condiciones en Ayuda de Gemini y Gemini API.

Evalúa el resultado con la rúbrica de CARS. Una buena configuración no elimina la necesidad de pruebas ni verificación humana.
