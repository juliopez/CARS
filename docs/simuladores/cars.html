¿Qué cambia al construir un prompt CARS?

Activa componentes, modifica su contenido y observa qué indicaciones recibe un modelo.

Volver al recorrido

1. Escenario de aprendizaje

Una asesoría ficticia registra el acuerdo de revisar ventas, pero no especifica responsable ni fecha. La IA debe organizar esa información sin inventar datos.

2. Prompt resultante

3. ¿Qué estás observando?
  • Desactivar C: se pierde el escenario específico de trabajo.
  • Desactivar A: puede desaparecer la tarea y una restricción esencial.
  • Desactivar R: no impide que el modelo responda; el rol es opcional cuando no aporta valor.
  • Desactivar S: se pierde el formato y parte del criterio de evidencia.
Importante: este simulador analiza la presencia textual de componentes, no mide calidad real ni garantiza que el modelo responda mejor. Para comprobar resultados utiliza el laboratorio CARS y ejecuta pruebas en una herramienta de IA.
4. Actividad de reflexión
  1. Desactiva solamente el Rol: ¿el prompt sigue siendo comprensible?
  2. Desactiva Acción y Salida: ¿puedes saber qué resultado concreto se espera?
  3. Activa todo, pero elimina la prohibición de inventar fechas: ¿qué riesgo aparece?
  4. ¿Es preferible un prompt más largo o uno que aporte información pertinente y verificable?
