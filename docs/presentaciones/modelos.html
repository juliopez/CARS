01 · Distinguir

Modelo ≠ aplicación ≠ herramienta

Modelo

Sistema entrenado que procesa entradas y produce resultados.

Aplicación

Interfaz o servicio con planes, archivos y funciones adicionales.

Herramienta

Funciones de búsqueda, cálculo, archivos o generación multimedia.

02 · Modalidades

Gratis, suscripción, API y local

  • Gratis: funciones y cuotas limitadas, variables por servicio.
  • Suscripción: límites y herramientas según plan.
  • API: facturación y permisos generalmente independientes.
  • Local: instalación, licencia, RAM/VRAM y mantenimiento propios.
03 · Especialidades

Elegir por la tarea

Texto y código

Redacción, programación y revisión.

Datos

Preferir análisis con cálculos ejecutados y reproducibles.

Multimedia

Leer imágenes no es lo mismo que generarlas; igual ocurre con video.

04 · Interpretar

¿Qué significa 8B?

8B = aproximadamente 8.000 millones de parámetros.

Estimación ideal de pesos de un modelo 8B: FP16 ≈ 16 GB; 8 bits ≈ 8 GB; 4 bits ≈ 4 GB.

El consumo real añade contexto, caché, buffers y otras necesidades. Más parámetros no garantizan mejores respuestas.

05 · No confundir

Parámetros, tokens y contexto

  • Parámetros: valores aprendidos por el modelo.
  • Tokens: unidades de procesamiento y facturación, según servicio.
  • Ventana de contexto: cantidad de tokens considerada en una solicitud.
  • Cuantización: precisión numérica reducida para disminuir memoria.

08 · Verificar

Una buena elección es justificable

  • Calidad del resultado y prueba realizada.
  • Acceso disponible, límites y costo.
  • Privacidad, fuentes y supervisión humana.
  • Documentación oficial vigente.
